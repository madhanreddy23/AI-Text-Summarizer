# 📝 AI Text Summarizer

A simple and efficient **Text Summarization Project** that shortens long paragraphs while keeping the important meaning. This project uses an **extractive summarization approach** by ranking sentences based on keyword frequency.

---

## 🚀 Features

- Summarizes long texts into shorter readable form
- Works with any English content (articles, essays, news, blogs, etc.)
- No heavy model required — fast and lightweight
- Works in Jupyter Notebook or Python script

---

## 🧠 How It Works

The summarizer:

1. Cleans input text
2. Splits it into sentences & words
3. Builds a **word frequency table**
4. Scores each sentence
5. Selects the top-ranked sentences to form the summary
